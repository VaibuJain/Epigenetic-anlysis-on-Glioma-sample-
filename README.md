# Epigenetic Analysis of Glioma Sample

## Overview
This project focuses on epigenetic analysis of glioma samples using sequencing data to identify methylation patterns and regulatory regions associated with tumor progression.

## Objectives
- Identify DNA methylation patterns in glioma
- Detect hypermethylated genes and regions
- Understand epigenetic regulation in cancer

## Workflow
1. Basecalling using Oxford Nanopore (Dorado)
2. Quality control of sequencing data
3. Alignment to reference genome
4. Methylation calling and extraction
5. Identification of differentially methylated regions
6. Downstream analysis and visualization

## Tools & Technologies
- Oxford Nanopore Sequencing
- Dorado Basecaller
- samtools, bedtools
- Python, R
- High-Performance Computing (HPC)

## Key Results
- Identified hypermethylated genes in glioma samples
- Generated methylation profiles for downstream analysis
- Produced processed datasets for further biological interpretation
